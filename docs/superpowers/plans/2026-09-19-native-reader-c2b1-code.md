# Native Reader C-2b-1 (Approved Window, Protocol 2, Nothing-Read Notice, Eval Harness, Deferred Minors) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This repo has NO git: the skill is adapted — no worktree, no commits, reviewers get file paths and run reproducing probes instead of reading diffs, and the controller keeps a ledger file in the session scratchpad.

**Goal:** Close every code item of the "Carried to plan C-2b" list that needs no real screen: the helper captures only the window main approved (protocol 2), long runs of cycles in which nothing is read become visible, the dev bundle survives macOS's own relaunch, the onboarding copy says what macOS really does, the core stops depending on the reader for homoglyph repair, the deferred minors of C-1 and C-2a are settled, and `reader:eval` exists — built and unit-tested, never yet run against a screen.

**Architecture:** One verified payload (93 files) developed and tested as a whole in a scratch copy of `app/`, installed byte-for-byte by a script that refuses unless every target file is exactly the version the payload was verified against. After the install, eight independent topic reviews probe it (each fix is reverted on a backup copy and its tests watched to fail). Everything that needs a real window — the acceptance numbers, the privacy measurements, the manual checklist — is plan **C-2b-2**, written after this plan from the real harness and run with the owner present.

## Global Constraints

- NO git at all: no init, commit, branch, push. Tasks end with a "Checkpoint" step.
- Never `cd`. Project scripts run from the repo root as `pnpm --dir app <script>`. Absolute paths everywhere else.
- **Never run `pnpm` against any copy of `app/` whose `node_modules` is a symlink** (2026-09-19 incident: pnpm tried to reinstall and to purge the real `node_modules` through the link; it stopped only because there was no TTY). In a scratch copy call the tools directly: `node <repo>/app/node_modules/vitest/vitest.mjs run --root <copy>`, `node <repo>/app/node_modules/typescript/bin/tsc --noEmit -p <copy>/tsconfig.json`, `node <copy>/scripts/build-native.mjs [--test]`.
- No downloads, no installs. cargo runs ONLY through `pnpm --dir app build:native` / `test:native` (`--offline --locked`). A missing crate means STOP and report; never remove the flags.
- Install files ONLY with `install.py`. Never retype, never "improve" a payload file while installing it. Never re-extract an older plan's code blocks over the code.
- **Characters.** Cheap models have corrupted non-ASCII characters in this repo, and in this session the file-writing tools DECODED backslash-u escapes into literal characters, inconsistently. Any fix that touches a file containing `✓ ❯ × → “ ”`, Portuguese accents or Cyrillic/Greek escapes is made with exact-string edits, or generated by a script from code points, and the bytes on disk are checked afterwards. Source files never contain a literal character from U+0370–U+03FF or U+0400–U+04FF.
- PRIVACY while executing: no agent makes the helper capture or recognise a real window, prints a window title or prints recognised text. Allowed without the owner: unit tests, the handshake (synthetic warm-up, `permission`, `shutdown`, stdin EOF), the stand-in smoke run. No agent sends `read` or `frontWindow` to a built helper. No agent opens, prints or copies anything under `~/Library/Application Support/Clave Agent Dev/` except `grep -o '"code":"[A-Z_]*"'` on its `app.log`.
- The dev bundle `~/Applications/Clave Agent Dev.app` is launched only through LaunchServices (`pnpm --dir app start:reader[:scripted]`, later `reader:eval`), never by running its executable. OWNER-only: quitting and re-creating the real bundle, anything in System Settings, `tccutil`, the keychain, deleting things in `~/Applications`.
- Thresholds of `src/readerEval/thresholds.ts` are the spec's and are never changed by an agent.
- Every topic is reviewed independently with reproducing probes. A new or changed test is proven by reverting its fix on a backup copy and watching it fail; the file is restored and compared with `cmp`. Never build or re-sync documents while a reviewer is mutating files: reviewers work one at a time on `app/`, or on their own scratch copy.
- At the end: `pnpm --dir app test` → **1430 passed in 84 files**; `pnpm --dir app typecheck` clean; `pnpm --dir app test:native` → **224 passed**; `pnpm --dir app build:native` with zero warnings; handshake `ALL CHECKS PASSED` (protocol 2); `pnpm --dir app smoke` → `SMOKE OK`.
- **A test must never import a script whose top level DOES something** (2026-09-19 incident: importing `scripts/dev-bundle.mjs` from its test ran it and re-created the owner's real bundle). Scripts gate their program half on being the entry point.

Decisions this plan makes (flag any before execution). "Cost" is what is lost if the decision is wrong.

| # | Decision | Why | Cost if wrong |
|---|---|---|---|
| D1 | A `read` with no usable `expect` answers `failed` and captures nothing. On a locked screen it answers `locked` (the lock check comes first). | A main that does not say what it approved is broken; `failed` is what surfaces through the loop's failure window. | A future main that forgets the field shows a reader problem after five reads instead of reading. |
| D2 | The helper compares the front window with `expect` three times: before the capture, after the capture and black check (before the cache lookup and recognition), and after recognition (before storing or answering). A window whose title ticks mid-read is refused in the helper instead of discarded in main: the same outcome for the user. |
| D3 | `ok` and `black` answers carry a numbers-only `stats` object (`captureMs`, `recogniseMs`, `cacheHit`, `width`, `height`, `bandPx`). | D6 | Barren outcomes: `noWindow`, `windowGone`, `black`, `windowChanged`, `denied`, `notKept`, `locked`. Productive: `kept` and a new outcome `unchanged` (the read worked, the screen is static). Never text, never a toolbar strip, never a title other than the harness's own. | Phase 0 showed unchanged pixels recognise identically, so re-reading one staging measures nothing; the 0.8686 came from a different window state. | About ten minutes per full run. |
